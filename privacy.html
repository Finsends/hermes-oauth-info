Data handling

Privacy notice

This notice describes the Google integration named Hermes Personal Assistant. It is for the owner's use, not a service accepting public users.

Google data accessed and purpose

With the owner's consent, the integration accesses calendar lists and event details, including dates, times, titles, descriptions and locations, to answer questions and assist with personal planning. Authorized scheduling operations can create, update or delete events. The existing Gmail read-only permission allows reading messages and metadata for requested summaries. It does not grant permission to send or modify mail.

Storage and processing

The application stores authorization credentials in its configured credential storage. Retrieved content and responses may be retained according to application settings. Relevant content may be processed by configured AI service providers when needed to answer a request. Processing and retention depend on the application and service settings.

Use and disclosure

Google data is used to provide the owner's requested assistant features. This integration does not sell Google data, publish it on this website, use it for advertising, or provide it as a public dataset. Account credentials are not part of this public repository. This website contains no assistant connection or access to private records.

Control, retention and deletion

The owner can revoke the integration in Google Account connections. Revocation stops future authorized access; it does not automatically erase previously retained local sessions, memories or backups. The owner controls those copies and can remove them separately. Copies processed by an AI provider are subject to that provider's retention controls. Calendar changes made before revocation remain in Google Calendar until edited or deleted.

This website

These static pages are hosted by GitHub Pages. They add no analytics scripts, cookies, forms or Google login. GitHub may process normal request information under its privacy statement.

Updates

This notice will be updated when the application's data practices change.
